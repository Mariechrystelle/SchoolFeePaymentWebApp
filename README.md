# School Fee Payment Web Application

A web-based school fee payment and management system developed to facilitate student fee payments and simplify fee management.

## Overview

The School Fee Payment Web Application provides a platform where students can manage their school fee payments while administrators can manage students, payments, fees, and related information.

The application is designed to make school fee management more organized and accessible.

## Features

* Student registration and login
* Student dashboard
* School fee payment
* Payment confirmation and receipts
* Payment history
* Student management
* Fee management
* Payment management
* Administrative dashboard
* Reports management
* Password reset and password management
* Contact and messaging functionality
* English and French language support

## Technologies Used

* **Python**
* **Flask**
* **MySQL**
* **HTML**
* **CSS**

## Database

The application uses **MySQL** for storing and managing application data.

Database setup scripts are available in the `HND/sql/` directory.

## Main Application Areas

### Student Portal

Students can:

* Register and log in
* Access their dashboard
* View fee information
* Make payments
* View payment information
* Access payment receipts

### Admin Portal

Administrators can:

* Manage students
* Manage fees
* Manage payments
* View reports
* Manage administrative information

## Installation

Clone the repository:

bash
git clone https://github.com/Mariechrystelle/SchoolFeePaymentWebApp.git


Navigate to the project:

bash
cd SchoolFeePaymentWebApp/HND


Install the required Python packages:

bash
pip install -r requirements.txt


## Configuration

Configure the required database and application environment variables before running the application.

Do not commit passwords, database credentials, secret keys, or other sensitive information to the repository.

## Running the Application

Start the Flask application:

bash
python app.py


Then open the application in your web browser.

## Project Purpose

This project demonstrates the development of a web-based school fee management and payment system using Python, Flask, MySQL, HTML, CSS, and JavaScript.
